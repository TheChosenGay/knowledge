# 谈判

## 学习资源

- **视频**：Chris Voss MasterClass（FBI 首席人质谈判专家，B 站有中字搬运）
- **书籍**：《Never Split the Difference》Chris Voss（中文版《强势谈判》）

## Chris Voss 核心技巧（待学习后补充）

### 1. 镜像（Mirroring）
重复对方最后 1-3 个关键词，引导对方继续展开，暴露更多信息。

### 2. 标签（Labeling）
用"听起来你觉得……"命名对方的情绪，让对方感到被理解，降低防御。

### 3. 校准问题（Calibrated Questions）
用"How"和"What"开头的开放式问题，让对方帮你解决问题而不是拒绝你。例如："你觉得我应该怎么做？"

### 4. 策略性同理心（Tactical Empathy）
不是同情，是主动识别并说出对方的立场和感受，获取信任和信息。

### 5. 指控审计（Accusation Audit）
在对方提出负面想法之前，主动说出来："你可能觉得这个价格太高了……"，先发制人消解阻力。

### 6. 不等价交换（Non-monetary Terms）
找到对你成本低但对对方价值高的东西来交换，创造双赢空间。

## 信息不对称博弈框架

### 信息四象限

|  | 你知道 | 你不知道 |
|---|---|---|
| **对方知道** | 公共信息 | 你的盲区 |
| **对方不知道** | 你的筹码 | 双方盲区 |

### 谈判前准备
1. 明确自己的 **BATNA**（最佳替代方案）
2. 推演对方的 BATNA
3. 标注必须隐藏的信息 vs 应主动释放的信息

### 谈判中
4. 先问后答 — 用开放式问题探测
5. 锚定 — 先出有理由的高锚点
6. 观察不一致 — 言行矛盾处藏着真实信息

### 谈判后
7. 复盘信息差 — 哪些猜对了，哪些没预料到
