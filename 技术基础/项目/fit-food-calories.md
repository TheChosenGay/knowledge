# 拍照识别食物热量方案

## 整体流程

```
拍照
  ↓
AI 识别食物名称 + 估算份量（返回范围值）
  ↓
展示给用户："检测到米饭约200g，番茄炒蛋约150g"
  ↓
用户确认或滑动微调（粗粒度 ±50g）
  ↓
查营养数据库 → 输出热量 + 营养素
```

核心思路：**AI 给合理默认值，用户只需确认或微调**，不要让用户从零输入克重。

---

## 识别方案选型

### 方案一：多模态大模型（推荐，快速验证）

直接把图片发给 GPT-4o / Gemini，让它返回结构化 JSON：

```swift
let prompt = """
这张图片里有什么食物？
估算每种食物的份量和热量，以JSON格式返回：
{"foods": [{"name": "米饭", "amount": "200g", "calories": 260}]}
"""
```

- **优点**：零训练，识别能力强，一天跑通
- **缺点**：需联网，API 费用，热量数字可能不准（建议只用它识别名称，热量查数据库）

**推荐做法：大模型只负责识别食物名称，热量从数据库查**，避免大模型瞎编营养数据。

### 方案二：专用食物识别 API

| 服务 | 特点 | 免费额度 |
|---|---|---|
| Nutritionix | 最全，支持中文，有餐厅数据 | 每天500次 |
| Edamam | 食谱分析能力强 | 每月1000次 |
| 百度菜品识别 | 国内，中餐覆盖好 | 有免费额度 |
| Clarifai Food | 专门食物分类模型 | 有免费层 |

### 方案三：本地 CoreML（离线）

```
食物图片
  ↓
MobileNet/EfficientNet（分类：这是什么食物）
  ↓
本地营养数据库（查热量）
```

- Apple Create ML 可用自定义数据集训练，导出 CoreML 直接集成
- 不依赖网络，延迟低
- 识别精度比大模型差，类别覆盖有限

## 份量估算方案

份量估算是最难的部分，同样的食物份量不同热量差几倍。

### 方案一：参照物估算（主流）

训练模型识别"手 + 食物"组合，用手的像素大小反推食物体积：

```
一个拳头     ≈ 米饭约150g
一个手掌厚1cm ≈ 肉类约85g
一茶匙       ≈ 油5ml ≈ 45kcal
```

薄荷健康采用此方案。

### 方案二：LiDAR 深度估算（精度最高）

iPhone Pro 系列有 LiDAR，可直接测体积：

```
LiDAR 扫描 → 食物三维点云 → 体积 → × 食物密度 → 重量
```

误差可控制在 20% 以内，但仅限 Pro 机型，实现复杂。

### 方案三：份量档位（最务实）

不追求精确克重，用模糊档位：

```
小份 / 中份 / 大份
半碗 / 一碗 / 一碗半
```

对普通用户误差 ±30% 可接受，体验远好于让用户称重。

### 方案四：大模型直接估（够用）

```
prompt: "图中米饭大概几克？碗是普通家用碗。"
→ "约200-250g"
```

误差 ±20-30%，对健身热量追踪够用。食物数据库本身也有误差，过度追求精度意义不大。

## 营养数据库选型

### 开放数据库

| 数据库 | 覆盖 | 中餐 | 获取方式 |
|---|---|---|---|
| **USDA FoodData Central** | 60万+食物，营养最全 | 很少 | 免费 API + 可下载 |
| **Open Food Facts** | 300万+全球食品 | 有但质量参差 | 免费 API + 可下载 |
| **中国食物成分表** | ~2000种中国食材和菜肴 | 最权威 | 无官方API，GitHub有整理版 |

### 商业 API

| 服务 | 特点 | 免费额度 |
|---|---|---|
| Nutritionix | 最全，中文搜索，餐厅数据 | 每天500次 |
| Edamam | 食谱+营养一体 | 每月1000次 |
| Spoonacular | 食谱分析强 | 每天150次 |

### 针对中国用户的推荐组合

```
中国食物成分表（基础食材，本地离线）
    +
Nutritionix API（加工食品、外卖品牌）
    +
大模型兜底（数据库没有的食物，AI 估算）
```

中国食物成分表 GitHub 整理版搜 `china-food-composition` 可找到 JSON/CSV 格式。

## 难点总结

| 难点 | 说明 |
|---|---|
| 份量估算 | 最难，同一食物100g和300g热量差3倍 |
| 混合食物 | 炒菜里的油、肉、菜比例难分离，误差20-30%正常 |
| 自制 vs 外卖 | 同名食物含糖量、用油量差异大 |
| 中餐覆盖 | 西方数据库对中餐覆盖差，需专门处理 |

真正需要精确的用户（运动员、糖尿病患者）本来就会用秤，普通健身用户接受模糊估算即可。
