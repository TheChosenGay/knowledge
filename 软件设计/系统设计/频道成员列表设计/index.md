# 频道成员列表设计

## 题目

为一个即时通讯产品设计频道成员列表系统。频道类似 Slack / Discord 的 Channel，用户可以加入频道、退出频道，客户端需要展示频道内的成员列表及每个成员的在线状态。

**功能需求：**
1. 用户加入 / 退出频道
2. 展示频道成员列表（支持分页）
3. 成员列表中显示每个人的在线状态（在线 / 离线）
4. 成员上线 / 下线时，频道内其他成员能感知到状态变化（近实时，秒级）

**非功能需求：**
1. 单频道最大成员数：10 万人
2. 平台总频道数：100 万个
3. 成员列表读取 QPS：10 万
4. 在线状态变更的推送延迟 P99 < 3s
5. 系统可用性 99.9%

**约束条件：**
- 用户总量：1000 万
- 平均每个用户加入 10 个频道
- 平均在线率：20%（同时在线约 200 万用户）
