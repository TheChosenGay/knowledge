# 投资

## 学习路径

```
金融基础 → 投资理念 → 炒股(主动投资) → 量化交易
                  ↘ 基金(辅助了解)
```

1. **金融基础** — 先搞清楚游戏规则：市场怎么运作、有哪些资产、股票是什么、怎么看财报、怎么给公司估值
2. **投资理念** — 建立思维框架：风险与收益的本质、市场是否可预测、各投资流派的核心逻辑
3. **炒股/主动投资** — 实操方法论：基本面分析选公司、技术分析找时机、行业研究看赛道
4. **量化交易** — 用编程做投资：策略类型、回测框架、因子投资、实盘部署
5. **基金** — 辅助配置：基金类型与选择逻辑
