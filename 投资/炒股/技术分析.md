# 技术分析

基本面回答"买什么"，技术分析回答"什么时候买卖"。不关心公司好坏，只看价格走势和市场情绪。

## 四个核心工具

### 1. 均线（MA）

N天收盘价的平均值，平滑短期波动看趋势。

```
MA5(一周) / MA10(两周) / MA20(月线) / MA60(季线) / MA120(半年) / MA250(年线，牛熊分界)
```

- 股价在均线上方 → 趋势向上；下方 → 向下
- **金叉**（短上穿长）→ 买入信号
- **死叉**（短下穿长）→ 卖出信号
- **多头排列** MA5>MA10>MA20>MA60 → 强势上涨

均线是趋势的滞后确认，不是预测。

### 2. MACD

- DIF（快线）上穿 DEA（慢线）→ 金叉看多
- DIF 下穿 DEA → 死叉看空
- **背离最有价值**：股价创新高但MACD没有 → 顶背离，动力衰竭可能要跌

### 3. RSI（相对强弱）

范围 0-100：
- \> 70 超买（可能回调）
- < 30 超卖（可能反弹）
- 强趋势中可长时间停留在超买/超卖区，不要单独用

### 4. 成交量

- **放量突破** — 突破阻力位 + 量大增 → 突破有效概率高
- **缩量回调** — 上涨中小幅回调但量很小 → 没人急着卖，趋势延续

## 支撑与阻力

- **支撑位** — 跌到就弹回的"地板"（前期低点、整数关口、重要均线）
- **阻力位** — 涨到就被挡的"天花板"（前期高点、套牢密集区）
- 支撑跌破后变阻力，阻力突破后变支撑

## 局限性

1. **滞后** — 信号出来时已错过最佳点位
2. **主观** — 同一张图不同人不同结论
3. **极端失效** — 涨跌停、黑天鹅中指标全废
4. **自我实现** — 大家看同样指标做同样操作

## 实际建议

技术分析当辅助工具，不当信仰：
- 基本面选好公司 → 技术分析找买卖时机
- 量化中将技术指标数值化为因子
