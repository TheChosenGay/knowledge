# 基本面分析

## 分析框架：自上而下

```
宏观经济 → 行业选择 → 个股分析
```

## 一、宏观经济速查

| 指标 | 含义 | 对股市影响 |
|------|------|-----------|
| GDP 增速 | 经济增长速度 | 高 → 企业盈利好 → 利好 |
| CPI（通胀） | 物价涨幅 | 温和(2-3%)好；高通胀 → 加息 → 利空 |
| 利率（LPR/MLF） | 央行货币政策 | 降息利好，加息利空 |
| 社融/M2 | 市场上的钱多不多 | 放水 → 利好 |
| PMI | 制造业景气度 | > 50 扩张，< 50 收缩 |

> 经济好 + 钱多 = 牛市基础

## 二、行业分析

三个维度：
1. **市场空间** — 行业多大？还能增长多少？
2. **竞争格局** — 几家分蛋糕？越集中龙头越赚钱
3. **生命周期** — 导入期（高风险高赔率）→ 成长期（最佳窗口）→ 成熟期（赚分红）→ 衰退期（避开）

## 三、个股分析指标速查表

### 盈利能力

| 指标 | 公式 | 看什么 | 参考值 |
|------|------|--------|--------|
| **毛利率** | 毛利润 / 营收 | 产品定价权，护城河深度 | >40% 优秀（茅台~90%，制造业~20%） |
| **净利率** | 净利润 / 营收 | 最终赚钱效率 | 行业差异大，看同行对比 |
| **ROE** | 净利润 / 净资产 | 用股东的钱赚钱的效率，巴菲特最看重 | **连续5年 >15% 是好公司标志** |

### 成长能力

| 指标 | 公式 | 看什么 | 参考值 |
|------|------|--------|--------|
| **营收增长率** | (今年-去年)/去年 | 公司在增长还是萎缩 | 看趋势，连续3年+增长 |
| **净利润增长率** | 同上 | 盈利变化 | 连续下滑是危险信号 |

### 估值（贵不贵）

| 指标 | 公式 | 看什么 | 怎么用 |
|------|------|--------|--------|
| **PE（市盈率）** | 股价 / 每股收益 | 按当前盈利几年回本 | 同行对比 + 历史分位，推荐看TTM |
| **PB（市净率）** | 股价 / 每股净资产 | 相对净资产贵不贵 | 适合重资产行业（银行、地产） |
| **PEG** | PE / 净利润增长率 | 考虑增长后贵不贵 | <1 可能低估，>1 可能偏贵 |
| **PS（市销率）** | 市值 / 营收 | 亏损公司的估值替代 | 互联网/SaaS早期用 |

### 财务健康

| 指标 | 公式 | 看什么 | 参考值 |
|------|------|--------|--------|
| **资产负债率** | 负债 / 资产 | 杠杆水平 | 非金融 <60%，银行高是正常的 |
| **流动比率** | 流动资产 / 流动负债 | 短期偿债能力 | >1.5 较健康 |

### 现金流质量

| 指标 | 看什么 | 参考值 |
|------|--------|--------|
| **经营现金流** | 日常经营的真金白银 | 应为正，越大越好 |
| **经营现金流 vs 净利润** | 利润是不是"真的" | 经营现金流 ≥ 净利润才健康 |

### 分红能力

| 指标 | 公式 | 看什么 |
|------|------|--------|
| **股息率** | 年度分红 / 股价 | 类似存款利率概念 |

## 四、快速筛选清单

拿到一家公司，按这个顺序过一遍：

```
□ 1. ROE 连续3年 > 15%？                → 赚钱效率
□ 2. 毛利率 > 40% 且稳定？              → 护城河
□ 3. 营收和净利润连续增长？              → 成长性
□ 4. 资产负债率 < 60%？                 → 财务安全
□ 5. 经营现金流 ≥ 净利润？              → 利润质量
□ 6. PE 在历史分位 < 50%？              → 不贵
□ 7. PEG < 1？                          → 增长匹配估值
```

全部打勾 = 好公司 + 好价格。实际中能过5条以上就值得深入研究。

## 五、完整分析模板

```
1. 公司干什么的？主营业务？
2. 行业空间多大？增长趋势？
3. 竞争格局：市占率？竞争对手？
4. 护城河：品牌？技术壁垒？规模效应？转换成本？
5. 财务：营收增速、净利率、ROE、现金流
6. 估值：PE历史分位？同行对比？
7. 风险：最大的不确定性？
```
