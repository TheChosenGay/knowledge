# 行业研究

选股之前先选行业。行业选对事半功倍。

## 行业分类

A股用**申万行业分类**，三级结构：

```
一级（31个）：食品饮料、电子、医药、银行、计算机...
  └─ 二级：白酒、乳品、调味品...
      └─ 三级：高端白酒、区域白酒...
```

实际研究通常在二级行业粒度。

## 核心分析框架

### 1. 市场空间与渗透率

| 指标 | 含义 |
|------|------|
| **TAM** | 总可触达市场规模（天花板） |
| **渗透率** | 当前规模 / TAM |

```
< 10%   → 导入期，高风险高赔率
10-30%  → 加速渗透，最佳投资窗口
30-60%  → 增速放缓
> 60%   → 成熟期，看格局和分红
```

### 2. 竞争格局：波特五力

```
            新进入者威胁
                ↓
供应商议价能力 → 行业内竞争 ← 买方议价能力
                ↑
            替代品威胁
```

最理想：寡头垄断、高壁垒、无替代、上下游议价弱（如高端白酒）。
最差：完全竞争、无壁垒、替代品多（如餐饮）。

量化指标：
- **CR5 > 60%** → 集中度高，龙头有定价权
- **CR5 < 30%** → 分散竞争，可能还在洗牌

### 3. 产业链位置

```
上游（资源/零部件）→ 中游（制造/组装）→ 下游（品牌/渠道）
```

- 上游：周期性强，受大宗商品影响
- 中游：两头受挤，毛利率最低
- 下游：品牌溢价高，毛利率通常最高
- 投资优先选**有定价权的环节**

### 4. 行业轮动（美林时钟简化版）

| 阶段 | 特征 | 强势行业 |
|------|------|---------|
| 复苏期 | GDP回升、利率低 | 科技、可选消费、地产 |
| 过热期 | 通胀升、加息 | 资源（煤炭石油）、周期品 |
| 滞胀期 | 高通胀、经济放缓 | 必选消费、医药（防御） |
| 衰退期 | 降息、经济底部 | 债券、高股息 |
