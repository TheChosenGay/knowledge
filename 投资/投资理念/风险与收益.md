# 风险与收益

## 风险的定义

投资中的风险 = **不确定性**（结果分布范围宽），不仅仅是"亏钱"。

## 风险分类

| 类型 | 含义 | 能否消除 |
|------|------|---------|
| **系统性风险** | 整个市场一起跌（金融危机、战争） | 不能，需配置负相关资产对冲 |
| **非系统性风险** | 个别公司/行业问题（造假、产品失败） | 能，分散投资消除 |

## 核心定律

### 1. 无风险利率 — 收益基准线

国债收益率 ≈ 无风险收益率（中国约 2-3%，美国约 4-5%）。超出部分 = **风险溢价**。

```
预期收益 = 无风险利率 + 风险溢价
```

### 2. 没有免费午餐

高收益必须承担高风险。"高收益零风险" = 骗局或隐藏风险。

### 3. 波动 vs 永久性损失

- **学术定义**：风险 = 波动率（标准差）→ 短线交易者关心
- **巴菲特定义**：风险 = 本金永久性损失概率 → 长期投资者关心
- 量化交易用学术定义，主动投资用巴菲特定义

## 关键指标

### 夏普比率（Sharpe Ratio）

单位风险获得多少超额收益：

```
夏普比率 = (投资回报率 - 无风险利率) / 波动率
```

- \> 1 不错，> 2 优秀，< 0 不如买国债
- 量化核心目标：提高夏普比率。年化15%夏普2.0 优于 年化50%夏普0.5

### 最大回撤（Max Drawdown）

从历史最高点到最低点的跌幅：

```
最大回撤 = (最高点 - 最低点) / 最高点
```

衡量最坏情况下的痛苦程度。提前知道自己能承受多大回撤，选择匹配的策略。
