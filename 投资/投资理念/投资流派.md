# 投资流派

## 全景图

```
投资流派
├── 基本面驱动
│   ├── 价值投资（买便宜的好公司）
│   └── 成长投资（买增长快的公司）
├── 价格驱动
│   ├── 技术分析（看图形和指标）
│   └── 趋势跟踪（跟着大方向走）
├── 数据驱动
│   ├── 量化投资（统计模型 + 因子）
│   └── 高频交易（毫秒级套利）
└── 被动策略
    └── 指数投资（买市场本身）
```

## 1. 价值投资

**信仰**：公司有内在价值，市场短期偏离长期回归。价格低于内在价值时买入。

- 代表：格雷厄姆（安全边际）、巴菲特（好公司合理价格）
- 方法：深研财报 → 算内在价值 → 安全边际买入 → 长期持有 → 集中持仓
- 优势：逻辑清晰，长期有效
- 劣势：需要极强耐心，选错公司代价大

## 2. 成长投资

**信仰**：利润高速增长的公司，即使当前不便宜，增长兑现后回报惊人。

- 代表：费雪、彼得·林奇（麦哲伦基金13年年化29%）
- 方法：关注营收增速、市场空间，用 PEG 代替 PE
- 优势：抓住大牛股回报惊人
- 劣势：增长不兑现就是"估值杀"

价值和成长不对立。巴菲特后期投苹果（成长），林奇也看估值。实操中常结合。

## 3. 技术分析

**信仰**：价格走势会重复，看图包含一切信息。

- 三大假设：价格包含一切信息 / 沿趋势运动 / 历史重演
- 工具：均线（MA）、MACD、RSI、布林带、支撑阻力位、K线形态
- 优势：提供明确买卖信号，适合短线
- 劣势：学术研究认为纯技术分析长期无法跑赢市场

部分技术指标在量化中被用作"因子"。

## 4. 趋势跟踪

**信仰**：不预测只跟随，有趋势跟上，结束离场。

- 代表：海龟交易法则、CTA策略
- 方法：突破买入，跌破卖出，不做预判只做反应
- 胜率低（30-40%），靠大赢覆盖多次小亏
- 劣势：震荡市反复止损

## 5. 量化投资

**信仰**：用数学模型系统性寻找超额收益，去除人为情绪。

- 代表：西蒙斯（大奖章基金30年年化66%）、AQR、Two Sigma
- 方法：数据验证异象 → 提炼因子 → 多因子模型 → 回测验证 → 程序化执行
- 优势：纪律性强，可回测，能同时处理大量股票
- 劣势：因子会失效（拥挤），过度拟合风险，黑天鹅无法预测

## 6. 指数投资（被动投资）

**信仰**：打不过市场就买市场本身。

- 代表：约翰·博格（先锋基金，发明第一只指数基金）
- 方法：买宽基ETF，定期定额，长期持有
- 优势：简单、费率低、长期跑赢大多数主动基金
- 劣势：只能获得市场平均收益

## 流派选择参考

| 特点 | 建议方向 |
|------|---------|
| 有耐心、能深入研究 | 价值/成长投资 |
| 喜欢看盘、反应快 | 技术分析 / 趋势跟踪 |
| 有编程能力、喜欢数据 | **量化投资** |
| 不想花太多时间 | 指数投资 |
| 资金量大、追求稳健 | 多策略组合 |
