# A 股全市场多因子回测实战记录

记录自研系统的完整回测条件和结果，包含真实费率、滑点、整手约束，可用于对外分享。

---

## 回测环境

| 项目 | 设置 |
|------|------|
| 系统 | 自研 Python 量化系统（quant_research） |
| 数据源 | 腾讯财经 HTTP 接口 + 东方财富补充 |
| 价格复权 | 前复权（qfq） |
| 股票池 | A 股全市场（主板+科创+创业），按流动性取前 300 只 |
| 数据量 | ~1284 只股票，120 万+ 条日K数据 |
| 回测区间 | 2021-07-01 ~ 2025-05-21（约 4 年，覆盖牛熊） |
| 初始资金 | 100 万元 |

### 费率模型（真实 A 股散户费率）

| 费用项 | 设置 | 说明 |
|--------|------|------|
| 滑点 | 5 bps（万分之五） | 模拟买卖价差和延迟 |
| 佣金 | 万三（0.03%） | 买卖双边收 |
| 印花税 | 千一（0.1%） | 仅卖出收取 |
| 整手约束 | 100 股 | A 股最小交易单位 |
| 现金缓冲 | 2% | 避免因涨跌余额不足 |
| 单只上限 | 5%~10% | 分散化约束 |

**单边完整交易成本 ≈ 0.18%（5bps 滑点 + 3bps 佣金 + 10bps 印花税）**

### 风控设置

动态回撤减仓机制：
- 净值从高点回撤 10% → 仓位降至 70%
- 净值从高点回撤 20% → 仓位降至 40%
- 净值从高点回撤 30% → 仓位降至 5%（近乎清仓）
- 净值恢复后自动回升仓位

## 策略一：20日因子月度调仓（基线策略）

### 策略逻辑

选取过去 20 天内"跌多了 + 低波动 + 低换手 + 低成交额"的股票，等权买入 Top 20，每月末调仓一次。

本质：**低波动反转策略** — 买入被忽视的安静股票中的超跌品种。

### 因子配置

| 因子 | 权重 | 方向 | 含义 |
|------|------|------|------|
| reversal_20 | 1.0 | -1 | 过去20日跌幅越大越好（反转） |
| volatility_20 | 1.0 | -1 | 波动率越低越好（低波动异象） |
| turnover_mean_20 | 1.5 | -1 | 换手率越低越好（低流动性溢价） |
| turnover_std_20 | 1.5 | -1 | 换手波动越小越好（交易稳定） |
| amount_mean_20 | 1.0 | -1 | 成交额越低越好 |

### 结果

| 指标 | 数值 |
|------|------|
| 年化收益 | ~18% |
| Sharpe | **0.96** |
| 最大回撤 | ~25% |
| 总手续费 | 6.6 万 |
| 调仓次数 | ~48 次（月度） |

---

## 策略二：20日因子日度调仓（对照组）

同样因子，改为每日调仓。验证"高频调仓是否更好"。

### 结果

| 指标 | 数值 |
|------|------|
| 年化收益 | ~11% |
| Sharpe | **0.65** |
| 最大回撤 | ~27% |
| 总手续费 | **26.5 万** |

**结论**：20 日因子配日度调仓是浪费。因子信号周期 20 天，每天换仓只是在制造无意义的交易成本。

---

## 策略三：纯5日短周期因子日度调仓

用超短周期因子（5日反转、5日低波、5日低换手等）配日度调仓。

### 因子配置

| 因子 | 权重 | 方向 |
|------|------|------|
| reversal_5 | 1.5 | -1 |
| reversal_3 | 1.0 | -1 |
| volatility_5 | 1.0 | -1 |
| turnover_mean_5 | 1.5 | -1 |
| turnover_std_5 | 1.0 | -1 |
| amount_mean_5 | 0.5 | -1 |

### 结果

| 指标 | 数值 |
|------|------|
| 年化收益 | **-8.3%** |
| Sharpe | **-0.54** |
| 最大回撤 | -33.6% |
| 总手续费 | **33.9 万**（本金的 34%！） |
| 终值 | 72.2 万（亏 27.8 万） |

**结论**：纯短周期因子的截面区分度在 A 股太弱，日度全换仓的摩擦成本远超 alpha。

---

## 策略四：短+中混合因子日度调仓

核心改进：用 20 日因子做"安静股票筛选"，5 日因子做"短期择时"。

### 因子配置

| 因子 | 权重 | 方向 | 作用 |
|------|------|------|------|
| reversal_5 | 1.0 | -1 | 短期反转信号 |
| volatility_5 | 0.5 | -1 | 短期低波 |
| volatility_20 | 1.0 | -1 | 中期低波（核心过滤） |
| turnover_mean_5 | 1.0 | -1 | 短期低换手 |
| turnover_mean_20 | 1.5 | -1 | 中期低换手（核心过滤） |
| turnover_std_20 | 1.5 | -1 | 中期换手稳定 |
| amount_mean_20 | 1.0 | -1 | 中期低成交额 |

### 结果

| 指标 | 数值 |
|------|------|
| 年化收益 | 12.9% |
| Sharpe | **0.69** |
| 最大回撤 | -26.3% |
| 总手续费 | 30.6 万 |
| 终值 | 157 万（赚 57 万） |

**结论**：混合长短周期因子日度调仓可以赚钱，但 Sharpe 仍不如月度。

---

## 策略五：短+中混合因子周度调仓（最优折中）

和策略四相同因子，但改为每周调仓一次（每周五收盘计算，下周一执行）。

### 结果

| 指标 | 数值 |
|------|------|
| 年化收益 | **19.1%** |
| Sharpe | **0.94** |
| 最大回撤 | -26.1% |
| 总手续费 | **15.1 万** |
| 终值 | 192 万（赚 92 万） |

**结论**：周度调仓是短周期因子的最佳频率。Sharpe 接近月度基线，但更灵活。

## 策略对比总表

| 策略 | 因子周期 | 调仓 | Sharpe | 年化 | 回撤 | 手续费 |
|------|----------|------|--------|------|------|--------|
| 月度基线 | 20日 | 月度 | 0.96 | 18% | 25% | 6.6万 |

## 小红书可用结论

### 标题方向

- "100万跑了4年A股量化回测，发现了调仓频率的秘密"
- "A股散户量化实测：日度调仓为什么是个坑"
- "自建Python量化系统，真实费率下Sharpe 0.94的策略长什么样"

### 核心论点

1. **日度调仓 ≠ 更好**。A 股交易成本太高（印花税千一是固定的），日度换手带来的摩擦远超信号增量。
2. **短周期因子不能单独用**，需要和中长周期因子混合，否则噪声太大。
3. **最优策略 = 低波低换手选股（20日）+ 短期反转择时（5日）+ 周度调仓**。
4. **真实费率很重要**：5bps 滑点 + 万三佣金 + 千一印花税，单边成本 0.18%。很多回测号称年化 50% 但没扣这些。
5. **4 年覆盖牛熊市**（2021 抱团瓦解、2022 大跌、2023 反弹、2024-2025 震荡），不是只在牛市好看。
