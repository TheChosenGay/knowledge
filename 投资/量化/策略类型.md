# 量化策略类型

量化不是一种策略，是一类方法论的统称。核心是：**用数据验证规律，用程序执行规律**。

## 策略全景图

```
量化策略
├── 趋势跟踪（动量）
├── 均值回归
├── 统计套利
│   ├── 配对交易
│   └── 跨期套利
├── 因子选股（Alpha策略）
└── 高频交易
```

---

## 1. 趋势跟踪（动量策略）

**逻辑**：涨的会继续涨，跌的会继续跌。动量效应是市场上最被学术验证的异象之一。

**实现方式**：
- 计算过去 N 天涨幅，选涨最多的买入
- 突破近期高点买入，跌破低点卖出（海龟交易程序化版本）
- 时间窗口：通常 1个月 ~ 12个月有效，1周内和36个月以上会反转

**代码思路（伪代码）**：
```python
# 过去20天涨幅作为动量信号
momentum = (price_today - price_20d_ago) / price_20d_ago
# 按动量排名，买入前20%，卖空后20%
```

**优势**：长期有效，跨资产（股票/期货/外汇/大宗商品都有效）

**劣势**：震荡市连续止损；转折点往往大亏；有"肥尾"风险

---

## 2. 均值回归

**逻辑**：价格偏离均值太远迟早会回来。和趋势跟踪完全相反的信仰。

**实现方式**：
- 统计股价相对于均线的偏离程度（布林带是它的直观版本）
- 计算 Z-score：`(当前价 - 均值) / 标准差`，超过 2 做空，低于 -2 做多
- 适合横盘震荡的股票，不适合单边趋势

**代码思路**：
```python
zscore = (price - price.rolling(20).mean()) / price.rolling(20).std()
# zscore > 2 → 超涨做空
# zscore < -2 → 超跌做多
```

**优势**：胜率高（价格大概率会回来），适合震荡市

**劣势**：趋势行情中会"越补越亏"；需要严格止损

---

## 3. 统计套利

利用两个高度相关资产之间的**价差**偏离均衡时进行交易。

### 配对交易（Pairs Trading）

**逻辑**：找两只高度相关的股票（如招商银行 vs 兴业银行），正常情况下价差稳定。价差异常扩大时，买便宜的卖贵的，等价差回归时获利。

**步骤**：
1. 找协整对（Cointegration Test）
2. 建立价差序列，计算均值和标准差
3. 价差超过 2σ → 开仓；回归均值 → 平仓

```python
# 价差（spread）= 股票A价格 - β × 股票B价格
spread = price_A - beta * price_B
zscore = (spread - spread.mean()) / spread.std()
```

**关键**：协整关系会失效（公司基本面变化），需要定期重新检验。

### 跨期套利

同一商品不同月份的期货合约价差套利，适合期货市场。

---

## 4. 因子选股（Alpha策略）

**最重要的量化方向**，后面单独一篇笔记详细讲。

核心思路：
- 学术研究发现某些"因子"能长期预测股票超额收益
- 常见因子：价值（低PE）、动量、质量（高ROE）、规模（小市值）
- 多个因子组合 → 多因子模型 → 系统化选股

这是国内量化私募（九坤、幻方、明汯等）的核心打法。

---

## 5. 高频交易（HFT）

**逻辑**：利用微小价差、订单流信息，在毫秒级内套利。

- 需要极低延迟（专线接交易所、co-location托管服务器）
- 资金门槛和技术门槛极高
- 个人基本无法参与，了解即可

---

## 策略对比

| 策略 | 持仓周期 | 胜率 | 盈亏比 | 适合市场 |
|------|---------|------|--------|---------|
| 趋势跟踪 | 周~月 | 低(30-40%) | 高(大赚小亏) | 单边趋势 |
| 均值回归 | 日~周 | 高(60-70%) | 低 | 震荡市 |
| 配对交易 | 日~周 | 较高 | 中等 | 任何市场 |
| 因子选股 | 月~季 | 中等 | 中等 | 长期有效 |
| 高频交易 | 秒~分 | 极高 | 极低 | 流动性好 |

---

## 关键认知

1. **没有万能策略** — 每种策略都有"死亡时期"，组合多策略才是正解
2. **趋势和均值回归是对立的** — 不能同时相信两个；实际中靠参数区分时间尺度
3. **容量限制** — 策略规模太大会自我破坏（冲击成本），大资金不能用小市值策略
4. **因子会失效** — 被发现、被交易、效果消失。需要持续研究新因子
