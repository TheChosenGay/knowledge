# 第一次因子回测：A股动量因子

## 目标

带着一个最简单的因子，完整走一遍：

```
取数据 → 构造因子 → 排名选股 → 月度调仓 → 计算收益 → 对比基准 → 判断是否有效
```

这次不是为了直接找到赚钱策略，而是为了建立回测骨架和研究习惯。

---

## 回测设置

| 项目 | 设置 |
|------|------|
| 数据源 | AkShare / Sina A股日线 |
| 股票池 | 14只手工选择的大盘股 |
| 区间 | 2021-01-29 到 2026-04-30 |
| 因子 | 12个月动量，跳过最近1个月 |
| 调仓 | 月度 |
| 持仓 | 动量最高4只，等权 |
| 基准 | 股票池等权 |
| 成本 | 单边交易成本 0.20% |

股票池包括：贵州茅台、五粮液、美的集团、招商银行、中国平安、中信证券、恒瑞医药、长江电力、紫金矿业、比亚迪、海康威视、中兴通讯、宁德时代、隆基绿能。

---

## 因子定义

```python
momentum = price.shift(21) / price.shift(252) - 1
```

含义：

- `price.shift(252)`：约一年前的价格
- `price.shift(21)`：约一个月前的价格
- 跳过最近1个月，是为了避开短期反转

这个因子问的是：

> 过去一年表现强，但最近一个月不计入的股票，未来一个月是否继续更强？

---

## 回测结果

| 指标 | 策略（含成本） | 基准 |
|------|---------------|------|
| 期末净值 | 1.117 | 1.130 |
| CAGR | 2.10% | 2.31% |
| Sharpe | 0.20 | 0.21 |
| 最大回撤 | -37.21% | -29.63% |

结论：

> 这版简单动量因子没有跑赢基准，而且最大回撤更大。

这是一个被证伪的 baseline，不是可实盘策略。

---

## 为什么这次没有赚钱

可能原因：

1. **股票池太小**：只有14只，统计意义弱。
2. **幸存者偏差**：股票池是事后手工选择的，不是历史真实成分股。
3. **单因子太粗糙**：只用动量，没结合估值、质量、波动、流动性。
4. **没有行业中性化**：可能阶段性押注某些行业。
5. **A股风格切换强**：动量因子会在震荡/反转行情中失效。
6. **持仓太集中**：只买4只，波动和回撤都较大。

### 1. 回测第一步是数据层

Yahoo 被限流、东方财富接口断连，最后切到 Sina 数据源。

实战中数据源必须有备用方案，不能只依赖一个接口。

这次结果不好，但有价值：说明简单动量在这个设定下不够好。

### 3. 成本必须加入

月度调仓也会产生换手，交易成本会吃掉收益。

```python
port_ret_cost = port_ret - cost_rate * turnover
```

### 4. 基准必须明确

这次基准不是沪深300，而是股票池等权。因为目标是判断：在同一批股票里，动量排序是否有增益。

## 关键术语

### 1. 调仓

调仓 = 按固定规则重新调整持仓。

比如本次策略是月度调仓：

```text
每个月最后一个交易日
→ 重新计算所有股票的动量分数
→ 选出排名最高的4只
→ 不在名单里的卖掉，新进名单的买入
```

例子：

```text
上个月持仓：A、B、C、D
这个月排名前4：B、C、E、F
调仓动作：卖出 A、D；买入 E、F；保留 B、C
```

调仓频率越高，策略越灵活，但交易成本也越高。

常见频率：日度、周度、月度、季度。

---

### 2. 换手率

换手率 = 这次调仓中，组合有多少仓位被换掉。

在组合层面，常用公式：

```python
turnover = sum(abs(new_weight - old_weight))
```

例子：

```text
旧持仓：A 25%，B 25%，C 25%，D 25%
新持仓：B 25%，C 25%，E 25%，F 25%
```

变化：

```text
A: 25% → 0%，变化 25%
B: 25% → 25%，变化 0%
C: 25% → 25%，变化 0%
D: 25% → 0%，变化 25%
E: 0% → 25%，变化 25%
F: 0% → 25%，变化 25%
```

组合换手率：

```text
25% + 25% + 25% + 25% = 100%
```

换手率越高，说明交易越频繁，手续费、印花税、滑点、冲击成本越高。

---

### 3. 滑点

滑点 = 你以为能成交的价格，和实际成交价格之间的差。

比如回测里用收盘价 10.00 元买入，但实盘下单时实际成交价是 10.05 元：

```text
滑点 = 10.05 - 10.00 = 0.05 元
滑点比例 = 0.5%
```

为什么会有滑点：

1. **买卖价差**：买一和卖一之间本来就有差价。
2. **流动性不足**：小票成交量少，你一买就把价格推高。
3. **下单延迟**：信号出来到订单成交之间，价格已经变化。
4. **涨跌停/停牌**：想买买不到，想卖卖不掉。

回测如果不考虑滑点，收益通常会被高估。

---

## 关键认知

> 第一个因子回测没赚钱是正常的。专业量化不是靠一个公式赚钱，而是靠持续生产、验证、淘汰和组合因子。

目标不是找到“神奇因子”，而是搭建一个可以不断发现和验证因子的研究系统。
