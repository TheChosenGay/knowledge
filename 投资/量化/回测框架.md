# 回测框架

回测（Backtest）= 用历史数据模拟策略的过去表现，验证策略是否真实有效。

**核心问题**：回测好≠实盘好。理解两者的差距是量化的核心技能。

---

## 回测的基本流程

```
1. 准备数据（历史价格、财务数据）
   ↓
2. 定义策略逻辑（何时买、何时卖、仓位多少）
   ↓
3. 逐日/逐周模拟运行
   ↓
4. 计算收益和风险指标
   ↓
5. 分析结果，判断是否值得实盘
```

---

## 核心评估指标

### 收益类

| 指标 | 含义 | 参考值 |
|------|------|--------|
| 年化收益率 | 折算成年度的平均回报 | > 15% 算不错 |
| 超额收益（Alpha） | 相对于基准（沪深300）的多余收益 | > 10% |
| 胜率 | 盈利交易 / 总交易次数 | 趋势策略 30-40%，均值回归 60-70% |

### 风险类

| 指标 | 含义 | 参考值 |
|------|------|--------|
| 最大回撤（Max Drawdown）| 从峰值到谷底的最大跌幅 | < 20% 较优 |
| 年化波动率 | 收益率的标准差 | 越低越好 |
| 夏普比率（Sharpe Ratio）| 超额收益 / 波动率，单位风险回报 | > 1.5 较好，> 2 优秀 |
| Calmar 比率 | 年化收益 / 最大回撤 | > 1.5 |

**最看重的两个指标**：夏普比率（收益是否值得承担风险）和最大回撤（你能否在最坏时候扛住）

## 回测的致命陷阱

### 1. 前视偏差（Look-ahead Bias）——最危险

在回测某天时，用了那天之后才公布的数据。

**常见错误**：
- 用年报数据时，以年报发布日而不是以报告期末日为准
- 财报发布有滞后（3月底才出去年年报），回测时要用"知道这个数据的最早日期"

```python
# 错误：用财报期末日
df['ROE'] = df['净利润'] / df['净资产']  # 3月31日的ROE，但4月底才公开
# 正确：用财报公告日（通常滞后3-6个月）
df['ROE_available_date'] = df['公告日期']
```

### 2. 幸存者偏差（Survivorship Bias）

只用现在还存在的股票做回测，忽略了已经退市的股票。

- 退市股票往往是表现最差的（财务造假、破产）
- 只用存活公司 → 回测结果人为美化
- **解法**：用包含退市股票的全量历史数据库（如 Wind 全量数据）

### 3. 过度拟合（Overfitting）——最隐蔽

策略参数在历史数据上被过度优化，对历史噪音拟合得太好。

```
你以为：发现了规律
实际上：记住了历史
```

**识别方法**：
- 参数太多（10个参数、5000条历史 → 严重怀疑）
- 换个时间段或市场，效果大幅下降
- 样本内表现远好于样本外

**解法**：
1. **样本外测试**：留最后20%数据不用于训练
2. **Walk-forward 滚动测试**：滚动窗口模拟真实决策过程
3. **参数稳健性检验**：参数稍微变动，结果不应剧烈变化

### 4. 交易成本低估

回测常常忽略或低估：
- 佣金（万3左右）
- 印花税（卖出 0.1%）
- **冲击成本（Slippage）**：你的买入操作本身会推高价格，大单尤其严重
- 价差（买一和卖一之间）

**经验**：单边成本至少按 0.2% 计算；高换手策略（日频）实际成本吃掉大量超额收益。

### 5. 未来函数

技术指标计算时不小心用了未来数据。

```python
# 错误：均线用 center=True，相当于用了未来数据
ma = price.rolling(20, center=True).mean()
# 正确：只用过去数据
ma = price.rolling(20).mean()
```

### 自写回测（推荐入门）

```python
import pandas as pd
import numpy as np

def backtest(prices, signals):
    """
    prices: DataFrame，股票每日收盘价
    signals: DataFrame，每日仓位信号（1=持仓，0=空仓，-1=做空）
    """
    returns = prices.pct_change()              # 每日涨跌幅
    portfolio_returns = (returns * signals.shift(1)).mean(axis=1)  # 组合日收益
    
    # 计算累积净值
    nav = (1 + portfolio_returns).cumprod()
    
    # 夏普比率
    sharpe = portfolio_returns.mean() / portfolio_returns.std() * np.sqrt(252)
    
    # 最大回撤
    drawdown = nav / nav.cummax() - 1
    max_dd = drawdown.min()
    
    return nav, sharpe, max_dd
```

## 回测结果的正确解读

**好的回测应该具备**：
- 样本内外表现接近（差距 < 30%）
- 夏普比率在不同时间段都稳定（非只有某几年很好）
- 参数敏感性低（±20% 参数波动，结果变化 < 20%）
- 能解释清楚为什么这个策略会有效（有经济学逻辑）

**红旗信号**：
- 回测年化 > 100%（大概率过拟合）
- 最大回撤极低但收益极高（可能有数据错误）
- 只在牛市有效（没有测过熊市）
- 无法解释逻辑，只说"数据表现好"

---

## 关键认知

> **回测不是用来证明策略有效的，而是用来证伪的。**

一个好的量化研究员应该努力让策略在回测中失败，找出所有可能让策略失败的原因，最后剩下的才值得信任。
