# 因子投资

因子投资是量化选股的核心方法论。核心思想：**某些可量化的特征能长期预测股票超额收益**。

## 什么是因子

因子（Factor）= 能解释或预测股票收益差异的可量化特征。

比如"低PE的股票平均回报更高"——PE 就是一个因子（价值因子）。

学术上叫做"异象"（Anomaly）：发现了市场上持续存在的规律，理论上有效市场假说无法解释。

---

## 五大经典因子

### 1. 市场因子（Beta）

- **含义**：承担市场风险的补偿
- **来源**：CAPM 理论，Fama-French 三因子模型的基础
- **逻辑**：高Beta股票预期回报更高（承担更多系统风险）

### 2. 规模因子（Size）

- **含义**：小市值股票回报高于大市值
- **来源**：Fama-French 1992年论文
- **逻辑**：小公司流动性差、信息不透明 → 风险溢价更高
- **量化**：按市值排名，做多小市值、做空大市值

> A股中小市值效应历史上非常显著，但近年"壳价值"消退后有所弱化。

### 3. 价值因子（Value）

- **含义**：低估值股票回报高于高估值
- **常用指标**：PE、PB、PS、EV/EBITDA
- **逻辑**：市场过度悲观 → 价格低于内在价值 → 均值回归
- **量化**：按 PB 从低到高排，买最低的 20%

### 4. 动量因子（Momentum）

- **含义**：过去表现好的股票未来继续表现好
- **来源**：Jegadeesh & Titman 1993年论文
- **时间窗口**：通常用过去 12 个月涨幅，跳过最近 1 个月（短期反转）
- **量化**：
```python
# 动量 = 过去252天涨幅（跳过最近21天）
momentum = price.shift(21) / price.shift(252) - 1
```

### 5. 质量因子（Quality）

- **含义**：高质量公司（盈利能力强、财务稳健）长期回报更好
- **常用指标**：ROE、毛利率、净利润增长、负债率（越低越好）
- **逻辑**：优质公司的持续盈利能力被市场低估
- **与价值结合**：巴菲特的方法 = 价值因子 + 质量因子

## 更多因子分类

| 大类 | 代表因子 | 含义 |
|------|---------|------|
| 估值 | PE、PB、PS | 越低越好（价值） |
| 盈利 | ROE、毛利率 | 越高越好（质量） |
| 成长 | 营收增速、利润增速 | 增长快（成长） |
| 动量 | 过去N月涨幅 | 惯性效应 |
| 波动率 | 低波动率 | 低波动异象（低风险反而高收益）|
| 流动性 | 换手率 | 低流动性溢价 |
| 技术 | 均线偏离、MACD | 技术指标量化版 |
| 另类 | 分析师预期修正、文本情绪 | NLP挖掘 |

## 正常怎么找因子

专业因子研究不是直接写公式，而是从"假设 → 数据 → 检验 → 入库 → 组合"的流水线里筛出来。

```
经济/行为假设 → 构造候选因子 → 清洗与中性化 → IC/分组回测 → 稳健性测试 → 加入因子库 → 组合优化
```

### 常见因子来源

| 来源 | 例子 | 核心问题 |
|------|------|----------|
| 经济逻辑 | 价值、质量、成长、杠杆 | 为什么这个特征应该有风险溢价？ |
| 行为金融 | 动量、反转、公告后漂移 | 投资者哪里系统性犯错？ |
| 市场微观结构 | 成交量、换手率、买卖盘口、订单流 | 交易行为里有没有短期预测信号？ |
| 基本面数据 | 财报、盈利预告、分析师预期 | 公司经营变化是否尚未被价格反映？ |
| 另类数据 | 新闻情绪、研报文本、招聘、供应链 | 非传统信息是否领先市场？ |
| 数据挖掘 | 大规模组合特征、机器学习 | 是否只是过拟合历史噪音？ |

### 机构一般怎么做

1. **有因子库**：几百到几千个候选因子，按估值、成长、质量、动量、波动、流动性、情绪、另类数据分类。
2. **有标准检验框架**：统一算 IC、Rank IC、分组收益、多空收益、换手率、行业暴露、市值暴露、衰减速度。
3. **有入库门槛**：不是回测赚钱就能用，必须有逻辑、样本外有效、换市场/换周期仍然稳健。
4. **有去相关流程**：新因子如果只是旧因子的变体，价值不大；真正有用的是提供新的独立信息。
5. **有生产监控**：入库后持续跟踪，一旦 IC 衰减、拥挤、换手过高，就降低权重或下线。

### 一个候选因子的基本检验

- **IC**：今天因子值和未来收益的相关性是否稳定为正/负？
- **分组收益**：按因子从低到高分成 5/10 组，最高组是否长期跑赢最低组？
- **单调性**：因子越强，未来收益是否越高？
- **换手率**：收益是否被交易成本吃掉？
- **中性化后是否还有效**：剔除行业、市值、Beta 暴露后是否还有收益？
- **样本外是否有效**：不用训练期调参，未来区间是否还能赚钱？

核心判断：**好因子 = 有逻辑 + 有统计证据 + 低相关 + 可交易 + 样本外稳健**。

## 机构如何管理因子

机构通常不会把因子散落在研究员电脑里，而是放进一套“因子生产系统”。

### 核心设施

| 设施 | 作用 |
|------|------|
| 数据仓库 / Data Lake | 保存行情、财报、成分股、公告、研报、另类数据 |
| 点时数据库 Point-in-time | 保证回测时只能看到当时已经公布的数据，防前视偏差 |
| 因子库 Factor Store | 统一保存因子值、版本、计算逻辑、覆盖范围、更新时间 |
| 研究平台 | Notebook、脚本、批处理任务，用来开发和检验新因子 |
| 回测引擎 | 统一处理调仓、成本、滑点、停牌、涨跌停、成交约束 |
| 风险模型 | 控制行业、市值、Beta、风格暴露，常见如 Barra 或自研风险模型 |
| 组合优化器 | 把因子分数转成真实持仓，加入仓位、换手、行业、流动性约束 |
| 监控系统 | 跟踪因子 IC、收益、换手率、拥挤度、衰减和异常数据 |
| 实盘系统 OMS/EMS | 订单管理、交易执行、成交回报、风控拦截 |

### 因子生命周期

```
研究想法 → 写因子 → 单因子检验 → 样本外测试 → 入因子库 → 组合使用 → 实盘监控 → 降权/下线
```

每个因子通常会有元数据：

- 因子名称、类别、作者
- 经济/行为逻辑
- 计算公式和数据依赖
- 更新频率（日频/月频/季频）
- 覆盖股票池
- IC、Rank IC、分组收益、换手率
- 与已有因子的相关性
- 当前状态：研究中 / 模拟盘 / 实盘 / 下线

### 机构都用 Python 吗

不全是。

- **研究层**：Python 最常见，适合 pandas、numpy、机器学习、快速试错。
- **数据层**：SQL、Spark、Flink、ClickHouse、DuckDB、kdb+ 都可能用。
- **回测层**：很多机构自研，可能 Python 外壳 + C++/Java 加速核心。
- **交易执行层**：更常见 C++、Java、C#、Go，因为要求稳定、低延迟、可控。
- **高频交易**：核心通常不用 Python，更多是 C++/FPGA/低延迟系统。

Python 是研究语言，不一定是最终交易系统语言。

### 开源会不会影响结果

开源本身不会让结果变差。真正影响结果的是：

1. 数据是否点时、干净、无幸存者偏差
2. 回测是否正确处理成本、滑点、涨跌停、停牌
3. 因子是否样本外有效
4. 组合构建是否控制风险暴露和换手
5. 实盘执行是否接近回测假设

开源库适合学习和原型验证；专业机构通常会在开源工具之上自研数据、回测、风控、交易和监控系统。

## 从单因子到可交易因子系统

实践中不要追求"所有因子"，而要搭建一条可重复的因子生产线。

```
单个因子验证
→ 多个候选因子库
→ 因子清洗/中性化
→ 因子有效性检验
→ 因子组合
→ 组合构建
→ 回测/模拟盘/小资金实盘
→ 持续监控和迭代
```

### 阶段 1：单因子

目标是学会判断一个因子有没有预测能力。

- 例子：动量、低PE、高ROE、小市值
- 看 IC、分组收益、换手率、最大回撤
- 重点不是赚钱，而是学会验证

### 阶段 2：因子库

把因子按大类组织：

| 大类 | 例子 |
|------|------|
| 估值 | PE、PB、PS、股息率 |
| 质量 | ROE、毛利率、资产负债率、现金流 |
| 成长 | 营收增速、净利润增速、EPS增速 |
| 动量 | 1/3/6/12个月涨幅、跳过最近1个月 |
| 反转 | 过去1周/1月跌幅后的反弹 |
| 波动 | 低波动率、最大回撤、下行波动 |
| 流动性 | 换手率、成交额、市值 |
| 情绪 | 涨停次数、龙虎榜、分析师预期、新闻情绪 |

### 阶段 3：因子清洗

原始因子不能直接用，通常要：

1. 去极值：处理异常值
2. 标准化：转成 z-score
3. 行业中性化：避免只是押注行业
4. 市值中性化：避免只是押注大小盘
5. 缺失值处理：财报缺失、停牌、上市时间太短

### 阶段 4：因子组合

常见方式：

- **等权打分**：最简单，适合入门
- **IC 加权**：最近表现好的因子权重大
- **风险平价**：让不同因子贡献相近风险
- **机器学习**：用模型学习非线性关系，但更容易过拟合

### 阶段 5：组合构建

因子分数不是最终持仓，还要加入约束：

- 单股仓位上限
- 行业偏离上限
- 换手率上限
- 流动性过滤
- ST/退市风险过滤
- 成本和滑点估计

### 赚钱导向的现实路径

如果目标是实践赚钱，顺序应该是：

1. 先做一个最简单的可解释策略
2. 严格回测，确认没有前视偏差和幸存者偏差
3. 加入真实交易成本后仍有超额收益
4. 模拟盘跑 1-3 个月，检查执行问题
5. 小资金实盘，先验证执行和心理承受能力
6. 逐步扩展因子和资金规模

不要直接全仓上复杂模型。量化亏钱通常不是因为因子不够多，而是因为数据、成本、过拟合、风控和执行出了问题。

## 多因子模型

单一因子不稳定，组合多因子可以平滑收益。

### Fama-French 五因子模型（学术标准）

```
股票超额收益 = α
    + β₁ × 市场因子(MKT)
    + β₂ × 规模因子(SMB)
    + β₃ × 价值因子(HML)
    + β₄ × 盈利因子(RMW)
    + β₅ × 投资因子(CMA)
    + ε
```

### 实务中的多因子选股

**步骤**：
1. 选定因子池（10-30个因子）
2. 对每个因子做标准化处理（去极值、中性化行业和市值）
3. 给每只股票打综合分（加权求和）
4. 按综合分排名，买入前 20%（或做多前20% 做空后20%）
5. 每月/每季度再平衡

```python
# 简化版多因子打分
score = (
    0.3 * rank(1/PE)      # 价值因子（越低PE排名越高）
  + 0.3 * rank(momentum)  # 动量因子
  + 0.2 * rank(ROE)       # 质量因子
  + 0.2 * rank(1/市值)    # 规模因子
)
# 按score排名，买入top 20%
```

## 因子的生命周期

```
发现异象 → 论文发表 → 机构交易 → 因子拥挤 → 效果衰减
```

**因子失效的原因**：
1. **拥挤**：太多人用同一因子，超额收益被套利掉
2. **基本面变化**：A股小市值效应随注册制深化而减弱
3. **过拟合**：回测中有效，实际中只是历史噪音

**应对**：
- 持续开发新因子（NLP、卫星数据、供应链关系等另类数据）
- 多因子组合，单因子失效不致命
- 定期检验因子有效性，动态调整权重

## 公开因子为什么不等于免费赚钱

经典因子公开后仍可能长期存在，但收益会变得更难拿。

原因有几类：

1. **风险补偿**：小市值、低估值股票往往更脆弱，收益高是承担了更大风险，不是无风险套利。
2. **行为偏差**：投资者会持续追热点、厌恶亏损、过度反应或反应不足，所以价值、动量等异象可能反复出现。
3. **执行约束**：机构有规模、流动性、风控、持仓限制，知道一个因子也未必能大仓位执行。
4. **摩擦成本**：换手率、滑点、冲击成本、税费会吃掉很多纸面收益。
5. **长期回撤**：因子可能几年都失效，大多数人扛不住回撤，所以长期收益不是人人都能拿到。

所以，公开因子更像是"可能存在的风险溢价/行为溢价"，不是提款机。

## 简单多因子模型的有效性边界

前面的简化模型：

```python
score = 0.3 * rank(1/PE) + 0.3 * rank(momentum) + 0.2 * rank(ROE) + 0.2 * rank(1/市值)
```

它是**教学模型**，不是可直接实盘的赚钱模型。

它的用途：
- 帮助理解多因子选股的基本结构
- 用来练习数据清洗、排序、调仓、回测
- 作为进一步研究的基线模型（baseline）

不能直接相信它有效。必须经过：
- 点时数据（point-in-time），避免前视偏差
- 包含退市股票，避免幸存者偏差
- 行业/市值中性化，避免因子其实只是押注某个行业或市值
- 加入真实交易成本、滑点、涨跌停、停牌限制
- 样本外测试、滚动测试、参数稳健性检验
- 观察 IC、IR、换手率、最大回撤，而不只看年化收益

判断标准不是"这个公式听起来合理"，而是：**扣除成本后，在样本外仍有稳定、可解释、可承受回撤的超额收益**。

## 因子中性化（重要细节）

直接用 PE 排名选股会有问题：不同行业 PE 差异巨大（银行PE低、科技PE高）。

**解决方法**：行业中性化
- 在每个行业内单独排名，而不是全市场统一排名
- 同时做市值中性化，避免因子暴露等价于押注某个市值区间

```python
# 行业中性化后的价值因子
for industry in industries:
    stocks_in_industry = filter_by_industry(industry)
    pe_rank_in_industry = rank(stocks_in_industry['PE'])
    # 用行业内排名替代全市场排名
```

## 关键认知

1. **因子不是圣杯** — 没有永远有效的因子，需要持续研究
2. **拥挤因子要回避** — 当所有人都知道某因子，超额收益就消失了
3. **因子暴露要清晰** — 你的组合实际在赌什么要心里有数
4. **换手率是成本** — 月度再平衡的摩擦成本会吃掉很多超额收益
