# 量化交易

用编程和数学模型系统化投资，去除情绪干扰，靠统计优势赚钱。

## 学习路径

```
策略类型 → 因子投资 → 回测框架 → 实盘部署
```

1. **策略类型** — 量化有哪些打法：趋势、均值回归、套利、因子选股
2. **因子投资** — 因子是什么、如何构建多因子模型、常见因子大全
3. **回测框架** — 如何用历史数据验证策略、避免过拟合和常见陷阱
4. **实盘部署** — 数据来源、执行框架、风控、滑点成本
