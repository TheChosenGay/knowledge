# 财务报表入门

上市公司每年披露四次财报：一季报（4月底前）、半年报（8月底前）、三季报（10月底前）、年报（次年4月底前）。

## 三张核心报表

| 报表 | 回答的问题 | 类比 |
|------|-----------|------|
| **资产负债表** | 公司**有什么** | 某一天的财产清单 |
| **利润表** | 公司**赚不赚钱** | 这个月的收支流水 |
| **现金流量表** | **手上有没有真钱** | 银行卡实际到账多少 |

## 1. 资产负债表（Balance Sheet）

某个时间点的快照。核心恒等式：

```
资产 = 负债 + 股东权益（净资产）
```

| 指标 | 公式 | 含义 |
|------|------|------|
| 资产负债率 | 负债 / 资产 | 杠杆水平，越高风险越大 |
| 流动比率 | 流动资产 / 流动负债 | 短期偿债能力，> 1.5 较健康 |
| 净资产 | 资产 - 负债 | PB 的分母来源 |

## 2. 利润表（Income Statement）

一段时间内（季度/年度）的经营成果，层层递进：

```
营业收入
 - 营业成本
 = 毛利润
 - 销售/管理/研发/财务费用
 = 营业利润
 ± 营业外收支
 - 所得税
 = 净利润  ← PE 的分子来源
```

| 指标 | 公式 | 含义 | 参考 |
|------|------|------|------|
| 毛利率 | 毛利润 / 营收 | 产品定价权 | 茅台 ~90%，制造业 ~20% |
| 净利率 | 净利润 / 营收 | 最终到手多少 | 茅台 ~50%，零售 ~3% |
| 营收增长率 | 同比变化 | 增长还是萎缩 | 看趋势比绝对值重要 |
| 净利润增长率 | 同比变化 | 盈利能力变化 | 连续下滑是危险信号 |

毛利率高 = 产品有定价权 = 护城河深。

## 3. 现金流量表（Cash Flow Statement）

**利润可以"做"（会计调整余地大），现金流很难"做"。**

| 类型 | 含义 | 健康信号 |
|------|------|---------|
| 经营活动现金流 | 日常经营的进出 | 应为正，越大越好 |
| 投资活动现金流 | 买卖设备/投资 | 成长期为负正常 |
| 筹资活动现金流 | 借还钱/分红 | 看结构 |

> **关键规则**：净利润高但经营现金流持续为负或远低于净利润 → 利润可能是"纸面利润"，重大警告信号。

## 快速判断框架

```
1. 营收和净利润在增长吗？          → 利润表
2. 毛利率高吗？稳定吗？            → 利润表（护城河）
3. 资产负债率高不高？              → 资产负债表（风险）
4. 经营现金流 ≥ 净利润吗？         → 现金流量表（利润质量）
5. 连续几年都满足以上条件吗？      → 看趋势而非单点
```

五个都过关，基本面不会太差。
