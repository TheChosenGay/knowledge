# 资产类别

所有投资归根结底就两件事：**要么你是老板（股权），要么你是债主（债权）**。

## 主要资产类别

### 1. 股票（Equity）

买了一家公司的所有权份额。收益来源：
- **资本利得** — 低买高卖赚差价
- **分红（Dividend）** — 公司利润分配给股东

高风险高收益。长期年化：A股沪深300约 8-10%，美股标普500约 10-12%。但单年亏 20-30% 很常见。

### 2. 债券（Bond）

借钱给政府或企业，对方定期付利息、到期还本金。

- **国债** — 政府发行，几乎无风险（中国10年期约 2-3%）
- **企业债/公司债** — 风险高于国债，利率更高
- **可转债** — 能转换成股票的债券，兼具债和股的特性，量化常用标的

**债券价格和利率反向变动**：票面利率是写死的常量，市场利率是变量。市场利率上升时，旧债券相对"不值钱"了，价格必须下降来匹配新的回报要求。

```
债券价格 = 未来现金流 / (1 + 市场利率)^n
```

分母变大，价格变小。

### 3. 基金（Fund）

一篮子资产的打包，不是独立的资产类别。
- **主动基金** — 基金经理选股，管理费约 1.5%/年
- **被动基金（指数基金/ETF）** — 跟踪指数，费率约 0.1-0.5%/年

### 4. 商品（Commodity）

黄金、原油、铜、农产品等实物资源。
- **黄金** — 避险资产，经济差/通胀高时涨
- **原油** — 和经济周期强相关
- 普通人通过期货合约或商品ETF参与

### 5. 衍生品（Derivatives）

价值"衍生"自标的资产。

**期货（Futures）** — 约定未来某天以某价格买/卖，双方都有义务履约。

**期权（Options）** — 付权利金买一个权利（非义务）。

| | 看涨期权（Call） | 看跌期权（Put） |
|---|---|---|
| 买方预期 | 涨 | 跌 |
| 获得的权利 | 以约定价**买入** | 以约定价**卖出** |
| 最大亏损 | 权利金 | 权利金 |
| 使用场景 | 看好上涨做多 | 做空投机 / 持股保险（Protective Put） |

看跌期权不需要先持有股票。例：股价100，花3元买行权价95的Put，跌到80 → 市场80买入、期权95卖出，赚12元；没跌 → 最多亏3元权利金。

### 6. 另类资产（Alternatives）

房地产（REITs）、私募股权（PE）、加密货币等。门槛高或流动性差，初期不用关注。

## 风险收益光谱

```
货币基金 → 国债 → 企业债 → 可转债 → 指数基金 → 股票 → 期货/期权 → 加密货币
  ~2%      ~3%    ~4-5%    ~5-8%    ~8-10%   ~10-15%    高杠杆      极高波动
```

> 没有"高收益低风险"的资产。如果有人告诉你有，要么在骗你，要么不懂风险在哪。

## 资产配置的核心：相关性

不同资产价格走势的关系叫**相关性（Correlation）**：
- **正相关** — 一起涨跌（同行业两只股票）
- **负相关** — 此涨彼跌（股票 vs 国债）
- **低相关** — 关系不大（A股 vs 黄金）

**分散投资的本质 = 持有低相关或负相关的资产**，降低整体波动。
