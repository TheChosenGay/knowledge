# 估值方法

财报告诉你公司好不好，估值告诉你**当前股价贵不贵**。好公司买贵了一样亏钱。

## 两大类

| 类型 | 思路 | 类比 |
|------|------|------|
| **相对估值** | 和同行比贵便宜 | 同小区均价 8万/㎡，这套 6万是不是便宜？ |
| **绝对估值** | 算未来现金流折算到今天 | 这套房未来30年能收多少租金，折回今天值多少？ |

## 相对估值法

### PE 估值

```
合理股价 = 每股收益 × 合理PE倍数
```

合理PE的三种参照：
1. **行业平均PE** — 同行对比
2. **历史PE区间** — 和自己的历史比
3. **PEG = PE / 净利润增长率** — 引入增长因素，PEG < 1 可能被低估

### PB 估值

```
合理股价 = 每股净资产 × 合理PB倍数
```

适用重资产行业（银行、保险、地产）。银行 PB 长期 0.5-1.2，PB < 0.7 可能是机会（前提资产质量没问题）。

### PS 估值（市销率）

```
PS = 市值 / 营收
```

适用**还没盈利的公司**（PE算不了）。互联网、SaaS 早期常用。

### EV/EBITDA

```
EV（企业价值）= 市值 + 净负债
EV/EBITDA 剔除了资本结构和折旧政策影响，跨公司对比更公平。
```

机构投资者和并购中常用。

## 绝对估值法

### DCF（现金流折现）

> 公司价值 = 未来所有自由现金流折算到今天的总和

```
公司价值 = Σ (第n年自由现金流 / (1 + 折现率)^n)
```

折现率 = 钱的时间价值。今天的100块比明年的100块值钱。

**问题**：对假设极其敏感，增长率改 2 个百分点估值差 30-50%。实操中更多用于理解逻辑而非精确计算。

### DDM（股息折现）

```
股价 = 下一年股息 / (折现率 - 股息增长率)
```

适合高分红稳定增长的公司（银行、公用事业、消费龙头）。

## 不同公司类型的估值选择

| 公司类型 | 首选 | 辅助 |
|---------|------|------|
| 成熟盈利 | PE + PEG | DCF |
| 重资产 | PB | PE |
| 亏损有营收 | PS | EV/EBITDA |
| 高分红 | DDM | PE + 股息率 |
| 周期行业 | PB | 不看PE（利润波动大PE失真） |

## 常见陷阱

1. **低PE ≠ 便宜** — 可能利润即将下滑，市场提前反映
2. **高PE ≠ 贵** — 可能高增长初期，未来利润爆发后PE快速下降
3. **PB < 1 ≠ 捡漏** — 净资产可能有水分（商誉减值）
4. **不同行业不能直接比PE** — 银行5倍和科技50倍没有可比性
