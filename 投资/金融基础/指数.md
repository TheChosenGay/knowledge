# 指数

指数 = **一篮子股票的加权平均表现**，是衡量某个市场或某类股票整体涨跌的统计指标。

## 怎么算

1. **选股** — 按规则选出成分股（如沪深300选市值最大流动性最好的300只）
2. **加权** — 按市值加权，大公司占比大
3. **算点位** — 设基准日和基准点位，每天根据成分股涨跌计算

## 中国主要指数

| 指数 | 成分 | 代表 |
|------|------|------|
| **上证指数** | 上交所全部股票 | 上海整体（含大量银行股，常被诟病失真） |
| **沪深300** | 沪深最大300只 | A股大盘蓝筹，最重要的宽基指数 |
| **中证500** | 排除300后最大500只 | 中盘成长 |
| **中证1000** | 再往下1000只 | 小盘股 |
| **创业板指** | 创业板最大100只 | 科技、医药、新能源 |
| **科创50** | 科创板最大50只 | 硬科技 |

美股：标普500（最重要全球基准）、纳斯达克100（科技）、道琼斯30（蓝筹）。

## 指数的四个用途

### 1. 市场温度计
看沪深300走势就知道大盘状态。

### 2. 业绩基准（Benchmark）
炒股赚15%，沪深300涨了25% → 跑输。超出指数的部分 = **Alpha（超额收益）**。

### 3. 直接投资（ETF）
指数本身不可交易，但 ETF 跟踪指数，像股票一样买卖：

| 指数 | ETF | 代码 |
|------|-----|------|
| 沪深300 | 华泰柏瑞沪深300ETF | 510300 |
| 中证500 | 南方中证500ETF | 510500 |
| 创业板 | 易方达创业板ETF | 159915 |

### 4. 量化中的 Alpha / Beta 拆解

```
总收益 = Beta（市场收益） + Alpha（超额收益）
```

- Beta — 跟着指数涨跌的部分，不是策略能力
- Alpha — 超越指数的部分，策略创造的价值
- 市场中性策略：选股获取Alpha + 做空指数期货对冲Beta → 不管大盘涨跌都赚钱

## 蓝筹股

"蓝筹"来自赌场蓝色筹码面值最大。**大蓝筹 = 市值大、盈利稳定、行业龙头**。特征：市值千亿+，连续多年分红，行业前二，波动相对小。沪深300权重股基本都是蓝筹。
