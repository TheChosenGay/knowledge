# 股票基础

## 一只股票的"身份证"

| 术语 | 含义 | 例子（贵州茅台 600519） |
|------|------|----------------------|
| 股票代码 | 唯一编号，开头判断板块 | 60xxxx = 沪主板 |
| 总市值 | 股价 × 总股本 | ~2万亿 |
| 流通市值 | 能在市场上交易的部分的价值 | ~2万亿 |
| 股本 | 公司总共发了多少股 | ~12.56亿股 |
| PE（市盈率） | 股价 ÷ 每股收益 | ~25倍 |
| PB（市净率） | 股价 ÷ 每股净资产 | ~8倍 |

## K线（蜡烛图）

一根K线 = 开盘价、收盘价、最高价、最低价的可视化：

```
    ┃  ← 上影线（最高价）
  ┏━━━┓
  ┃   ┃ ← 实体（开盘价 到 收盘价）
  ┗━━━┛
    ┃  ← 下影线（最低价）

A股：红涨绿跌    美股：绿涨红跌
```

## 成交量与成交额

- **成交量（Volume）** — 交易了多少股
- **成交额（Turnover）** — 交易了多少钱

判断市场情绪：
- 放量上涨 → 买盘强，上涨有支撑
- 缩量上涨 → 买盘弱，涨势可能不持久
- 放量下跌 → 恐慌抛售
- 缩量下跌 → 卖盘衰竭，跌势可能接近尾声

## 委托与撮合

下单 = 挂委托，不是直接成交。

- **买一 / 卖一** — 当前最高买价 / 最低卖价
- 两者之差 = **买卖价差（Bid-Ask Spread）**

### 集合竞价（9:15-9:25）

开盘前收集所有买卖委托，算出**成交量最大的价格**作为开盘价。规则：买价 >= 该价格的都愿意买，卖价 <= 该价格的都愿意卖，取 min(买量, 卖量)。

| 时段 | 规则 |
|------|------|
| 9:15-9:20 | 可提交可撤单（试探阶段，大资金常假挂单） |
| 9:20-9:25 | 只能提交不能撤单（锁定阶段，更真实） |
| 9:25 | 撮合出开盘价 |
| 9:25-9:30 | 系统处理，不接受委托 |

### 连续竞价（9:30-15:00）

实时撮合，**价格优先、时间优先**。

## 核心术语

| 术语 | 含义 |
|------|------|
| 涨停/跌停 | 触及当日涨跌幅上限/下限 |
| 换手率 | 成交量 ÷ 流通股本，衡量交易活跃度 |
| 股息率 | 年度分红 ÷ 股价 |
| 融资融券 | 借钱买股（融资/做多）或借股卖出（融券/做空） |
| 龙虎榜 | 异常波动时公布买卖前五营业部，观察主力资金动向 |

## PE 和 PB

**PE（市盈率）= 股价 / 每股收益**
- 含义：按当前盈利水平，多少年回本
- 静态PE 用去年利润，TTM PE 用最近4季度（推荐TTM）
- **必须同行业对比**：银行 5-8倍正常，科技 50倍也不算离谱

**PB（市净率）= 股价 / 每股净资产**
- 适合重资产行业（银行、地产、钢铁）
- 对轻资产行业（互联网、软件）意义不大
- PB < 1 叫"破净"，理论上低于清算价值
